# Immunology Companion — Android app (v2.13.0)

Offline WebView wrapper for the **v2.13.0** bilingual Immunology Learning Companion
(M.Sc. Zoology, Units I–V, GASC Nagercoil).

**Repo:** https://github.com/rameshgascngl-create/Immunology-Android

Package `edu.gascnagercoil.immunology` · versionName **2.13.0** · versionCode **2**

## Use this build

The complete project (including `js/app.js`) is the downloaded zip **ImmunologyAndroid_v2_13.zip**.
Open that folder in Android Studio and Run.

This GitHub tree is updated to v2.13.0 for the wrapper, Gradle version, and `index.html`.
The large course file `app/src/main/assets/immunology/js/app.js` must be copied from that zip (GitHub file API cannot carry the 600 KB bilingual dataset in one upload).

GitHub UI: **Add file → Upload files** → drop `app.js` into `app/src/main/assets/immunology/js/`.

After that, Actions will build an APK that actually contains the course.
